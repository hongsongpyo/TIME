다변량 시계열 이상탐지 결과

상단 요약 카드로 전체 탐지 결과를 확인하고, 아래 메뉴에서 원하는 그래프를 선택해 확인하세요.

이상탐지 대시보드

그래프를 아래로 길게 나열하지 않고, 메뉴를 선택해 필요한 결과만 확인할 수 있습니다.

전체 시계열

각 변수의 시계열 흐름과 이상 시점 marker를 함께 확인합니다.

Anomaly Score

시점별 이상 점수와 threshold 기준선을 비교합니다. 민감도가 높을수록 threshold가 낮아져 더 많은 이상을 탐지합니다.

변수별 이상 기여도

이상으로 판단된 시점에서 어떤 변수가 가장 크게 영향을 주었는지 확인합니다.

선택 이상 시점

이상 목록에서 특정 시점을 선택하면 해당 시점의 변수별 기여도가 표시됩니다.

Rank Variable Mean Score Max Score Contribution Anomaly Count

변수 × 시간 이상도 히트맵

행은 변수, 열은 시간이며 색이 진할수록 해당 변수의 이상 점수가 큽니다.

이상 시점 목록

이상 점수가 높은 순서대로 정렬된 Top anomaly 목록입니다. 행을 클릭하면 변수 기여도 메뉴에서 해당 시점의 상세 원인을 확인할 수 있습니다.

Rank Date Score Top Variable Type Description

이상 유형 요약

탐지된 이상 시점을 전역 이상, 맥락 이상, 패턴 이상, 다변량 동시 이상 등으로 요약합니다.

Type Count

데이터 품질 요약

결측치, 보간 여부, 사용자가 보호한 특이치 셀 정보를 확인합니다.

Column Missing Count Protected Count

이상탐지 해석 요약

분석 방식, 민감도, 이상 비율, 주요 이상 변수 등을 문장으로 정리합니다.
