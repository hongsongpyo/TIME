데이터 편집 및 이상탐지 설정

CSV 데이터를 직접 수정한 뒤, 다변량 시계열 이상탐지를 실행하세요. 숫자형 컬럼 전체를 기준으로 anomaly score, 이상 시점, 변수별 기여도를 계산합니다.

분석 모드
다변량 이상탐지 날짜/시간 컬럼을 자동으로 찾고, 나머지 숫자형 컬럼을 모두 사용해 시점별 이상 점수와 변수별 이상 기여도를 계산합니다.
민감도 설정 낮음은 확실한 이상만 적게 탐지하고, 보통은 기본 기준으로 탐지하며, 높음은 threshold를 낮춰 더 민감하게 이상 시점을 탐지합니다.
특이치 설정 특이치 설정 버튼을 누른 뒤 특정 셀을 클릭하면 해당 셀만 보호됩니다. 같은 행의 다른 변수까지 자동으로 보호하지 않습니다.
셀과 컬럼명을 직접 클릭해서 수정할 수 있습니다. 특이치 설정 버튼을 누른 뒤 셀을 클릭하면 분석에서 보호할 수 있습니다.
